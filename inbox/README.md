# Inbox

Jogue aqui qualquer material bruto: textos, fotos do caderno, PDFs, links soltos.
Depois rode `/processar` no Claude Code.

Dicas para fotos melhores de transcrever:
- luz uniforme, sem sombra da mão/celular; página inteira e reta no enquadramento
- uma página por foto; nomeie (ou diga na mensagem) **data e disciplina** se puder
  — ex.: `2026-11-12-neurociencia-do-consumo-p1.jpg`

Opcional: crie um `.txt` com o mesmo nome da foto para dar contexto
("aula do prof. X, foco em memória de marca; a seta da p2 liga ao esquema da p1").
